# Prepositions Quiz --- учебный проект

> README фиксирует согласованные решения, проверенные этапы и следующий
> шаг. Непроверенные детали отмечаются отдельно.

## 1. Цель проекта

Создать графическую викторину для Windows и изучать Python на реальном
проекте --- от консольной версии к графическому приложению.

### Подтверждённые требования

-   В каждом вопросе ровно 3 варианта ответа.
-   Ровно 1 вариант правильный.
-   За правильный ответ начисляется 1 очко.
-   Некорректный ввод не должен пропускать вопрос: программа должна
    запросить ответ повторно.
-   Планируются графический интерфейс и анимации.
-   Сами вопросы не должны становиться сложнее; со временем варианты
    ответа могут становиться более похожими.

## 5. Игровая логика и валидация

В `game_logic.py` вынесены функции:

-   `get_categories(questions)`
-   `get_questions_by_category(questions, category)`
-   `check_answer(user_answer, correct_answer)`
-   `calculate_score(results)`
-   `calculate_percentage(score, total_questions)`

Валидатор проверяет, в частности:

-   список вопросов не пуст;
-   обязательные поля присутствуют;
-   у каждого вопроса ровно три варианта ответа;
-   правильный ответ --- целое число от 1 до 3 (значение `bool` не
    принимается);
-   текст вопроса и варианты ответов не пустые;
-   категория указана корректно.

## 6. Backend API

Подтверждённые endpoints:

  ------------------------------------------------------------------------------------
  Метод                   Endpoint                             Назначение
  ----------------------- ------------------------------------ -----------------------
  `GET`                   `/`                                  Проверка работы API

  `GET`                   `/categories`                        Получение категорий из
                                                               SQLite

  `GET`                   `/questions`                         Получение вопросов;
                                                               можно передать
                                                               категорию

  `POST`                  `/quiz/session`                      Создание игровой сессии

  `POST`                  `/quiz/answer`                       Отправка ответа в
                                                               рамках сессии

  `GET`                   `/quiz/session/{session_id}/score`   Получение результата
                                                               сессии
  ------------------------------------------------------------------------------------

### Важные правила API

-   Правильный ответ и полный текст правильного ответа не должны
    раскрываться в обычном ответе `GET /questions`.
-   Ответ отправляется с `session_id`, `question_id` и `answer`.
-   Ответ на один и тот же вопрос в одной сессии можно отправить только
    один раз.
-   Повторная отправка возвращает **HTTP 409 Conflict**.
-   Неизвестная сессия или вопрос обрабатываются как ошибка
    отсутствующего ресурса.
-   Некорректные данные запроса проверяются FastAPI/Pydantic.

### Запуск backend

Из корневой папки проекта:

``` powershell
python -m uvicorn api:app --reload
```

Остановка сервера: `Ctrl + C`.

Swagger UI:

`http://127.0.0.1:8000/docs`

## 7. База данных SQLite

Используются таблицы:

-   `categories` --- категории;
-   `questions` --- вопросы и правильный номер ответа;
-   `answer_options` --- три варианта ответа для вопроса;
-   `quiz_sessions` --- игровые сессии;
-   `quiz_results` --- ответы и результаты пользователя.

Исходные вопросы загружаются в базу через seed-функцию. При
первоначальной проверке загрузки было получено:

-   2 категории;
-   4 вопроса;
-   12 вариантов ответа.

### Основные функции `database.py`

-   `get_connection()`
-   `create_tables()`
-   `seed_questions()`
-   `get_categories_from_db()`
-   `get_questions_from_db(category=None)`
-   `get_question_from_db(question_id)`
-   `create_quiz_session(category=None)`
-   `save_quiz_answer(session_id, question_id, selected_answer)`
-   `get_quiz_score(session_id)`

Повторная отправка ответа блокируется специальным исключением
`QuestionAlreadyAnsweredError`.
